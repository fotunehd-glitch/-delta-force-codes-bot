# MAP MARKERS for the Maps tab on deltaforcerandomkit.com
# The site reads this file on every visit, so adding markers here does NOT need a Netlify deploy.
# New markers show on the site within about 5 minutes.
#
# One marker per line:   Map | Floor | Type | X | Y | Name (optional)
#   Map:   Zero Dam, Layali Grove, Space City, Brakkesh, Tide Prison, AZ3 Nuclear Plant
#   Floor: - for maps without floors, or F1..F4 (Tide Prison), 1F..3F (AZ3)
#   X, Y:  0 to 1000 across the map picture (0,0 = top left, 1000,1000 = bottom right)
#
# Easiest way: open https://deltaforcerandomkit.com/#maps-edit , pick a map and a type, click the spot,
# then press "Copy lines" and paste them at the bottom of this file.
#
# Types:
#   Spawns & extracts: Spawn, Extract, Paid extract, Conditional extract
#   Doors & keys: Door code room (shows today's door code on the map), Keycard room
#   Loot: Safe, Small safe, Weapon crate, Large weapon crate, Ammo crate, Computer, Server, Hidden stash, Medical crate, Bird nest, Travel bag, Toolbox,
#         Flight case, Premium storage box, Premium suitcase, Briefcase, Courier carton, Field supply box, Large toolbox, Tool cabinet, Drawer,
#         Garbage bin, Computer case, Military med kit, Pile of medical supplies, Piece of clothing, Climbing bag, Combination lock, Cement truck, Red loot spot
#   Events & bosses: Protocol crate, Boss, Raven deal
#   Getting around: Zipline
#   Other: Other
#
# New types: just use a new name in a marker line and it gets its own entry in the list.
# To choose its group, colour and letters, add a line like:  Type | Hidden room | Loot | #ff9900 | HR
#
# Icons: a line like  Icon | Small safe | small-safe.png  uses map-icons/small-safe.png for that type.
# Types without an icon show a coloured letter dot.
#
# Lines starting with # are ignored. To remove a marker, delete its line.

# Map pictures: a line like  Picture | Zero Dam | - | zero-dam.webp  uses map-images/zero-dam.webp.
# For floors, one line per floor in order, e.g.  Picture | Tide Prison | F1 | tide-prison-f1.webp
# To change a map picture: upload the new file to map-images/ with a NEW name (e.g. zero-dam-s12.webp)
# and change the line here. (Reusing an old name can take up to 12 hours to show.)
